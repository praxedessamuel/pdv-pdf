# Índice dos fontes do PDV (ADVPL/TLPP)

Este README funciona como guia de consulta para os volumes PDF com o código-fonte do projeto. Os nomes abaixo são os caminhos e arquivos que aparecem nos volumes; use a busca do leitor de PDF para localizar o nome do fonte ou programa.

**Coleção:** 19 PDFs, 261 fontes catalogados.

> Os números indicam a página inicial do fonte no PDF. Os volumes reúnem fontes em sequência e não representam necessariamente módulos independentes. O nome do arquivo é o identificador mais seguro para busca; nem todo fonte corresponde a um ponto de entrada executável.
